## Copilot AI 资产

| 类型 | 项目资产 | 触发方式 | 作用 |
| --- | --- | --- | --- |
| Instructions | `.github/copilot-instructions.md` | 工作区对话自动加载 | 项目架构、安全和协作边界 |
| Custom Agent | `.github/agents/recorder-generation.agent.md` | 用户显式选择并粘贴Job路径 | 唯一公开入口、固定工具集和Agent-scoped Hook |
| Skill | `.github/skills/recorder-generate/SKILL.md` | Agent内部加载 | 受绑定Job的完整生成流程 |
| Prompts | `/collaboration-review`、`/collaboration-promote` | 框架负责人手动运行 | 形成协作候选或晋升明确批准的候选 |
| Hook wrapper | `.github/hooks/scripts/recorder-generation.ps1` | Agent Hook在Windows执行 | 选择可用Python并运行确定性路由器 |
| Hook | `.github/hooks/shadow-companion.json` | 新 Agent 会话开始 | 校验本地恢复状态并注入短指针 |

Agent、Skill和Hook只是 Copilot 的发现/宿主控制层：用户选择固定Agent，Agent加载Skill，
其内嵌Hook把该会话绑定到一个Job。Recorder Evidence、Request、Plan、Transaction、
Knowledge 和 Portable Knowledge 是 Python/文件协议，不是另一套 Agent 状态。Hook不保存
Workflow状态，Python owner仍负责Job transition和验证。该层不需要 MCP 或网络服务器。

VS Code Agent Chat 可直接运行Skill并提供原生修改文件/保留/撤销。其他宿主只有在能提供
等价原生编辑归属时才能完成同一交付，不得用后台文件写入冒充。

## 手动协作复盘

Collaboration Review 和 Promotion 只由框架负责人明确手动执行，不提供 SessionStart
提醒、会话计数、时间阈值或自动规则修改。仓库无法认证组织角色；负责人身份属于外部
治理。

手动生成候选：

```text
/collaboration-review
```

Review 只保存 Session ID、turn index 和短证据摘要，输出到被 Git 忽略的
`Bdd/ai/knowledge/collaboration-reviews/`。候选始终是 `proposed`，不会自动生效。

晋升时必须在当前请求中给出精确候选 ID：

```text
/collaboration-promote Bdd/ai/knowledge/collaboration-reviews/<review-id>.json candidate-01
```

“应用有益规则”之类模糊表达不算批准。批准项只能进入一个最小作用域：User memory、
仓库 Instructions、文件范围 Instructions、按需 Prompt 或长期 `ai/context`。低置信度或
没有目标的候选不能晋升。

安全边界：

- 不后台分析完整聊天，不按活动主动建议复盘。
- 不自动 Review、Promotion 或修改规则。
- Review 报告和 Promotion 回执默认不进入 Git。
- 规则修改必须可验证、可回滚，并保持原安全门。
- Shadow Companion 只保存短恢复状态；它不保存源码、终端原文、凭据或聊天正文。

## 维护原则

- 业务代码只写在 `Bdd/`，通用能力写在 `autowork_core/`。
- 修改动作 API 时同步更新 [动作参考](../3.动作参考.md) 和机器生成契约。
- 修改标签或 Step 规则时同步更新 [编写自动化脚本](../2.编写自动化脚本.md) 和测试。
- 修改配置语义时同步更新 [定位器和配置](../4.定位器与配置.md)。
- 修改 Recorder 协议时同步更新 [Recorder 设计](3.Recorder设计.md) 并运行风险适配回归。
- 修改长期 AI 边界时更新 `ai/context` 权威正文，不新增导航薄页。
- 修改 Shadow Companion 时证明 Recorder、Bdd 和 runtime 不反向依赖它，并保留完整 fallback。
- 修改文档后运行：

  ```powershell
  python -m autowork_core.utils.debug_tools.documentation_check --project-root .
  ```
